# ☕ Cafe Arome
A modern, full-stack cafe website with a public-facing menu and reservation system, plus a secure admin dashboard for managing bookings in real time.
**[🔗 Live Demo](https://alaahmidi154.github.io/1st_Internship_Website/)**

---

## ⚙️ Features
- **Elegant public site** — hero, menu, reservations and about sections
- **Live reservation system** — customers submit bookings
- **Secure admin dashboard** — authenticated-only access
- **Fully responsive** — works across desktop and mobile
